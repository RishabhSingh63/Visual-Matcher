This demo implements a web app that accepts an uploaded image and returns visually similar products using a simple server-side color-based similarity measure. I generated a small product dataset (50 images) with metadata. The Flask backend computes the average RGB color for the uploaded image and compares it to stored product averages, returning the closest matches with a normalized similarity score. The React frontend offers file upload, preview, loading states, and displays results with product thumbnails and metadata. For production, replace the color heuristic with robust image embeddings (CLIP / ResNet), store vectors in a vector DB (FAISS, Pinecone), and perform efficient nearest-neighbor search. Additional improvements include image preprocessing, more metadata filters, pagination, and a hosted deployment (Render / Vercel + Heroku/Render for backend).
